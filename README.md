# ViaSwift App Build Configuration

This repository contains the essential build configuration files for ViaSwift mobile app deployment.

## Build Scripts

- **build-for-appflow.sh**: Prepares the correct directory structure for AppFlow builds
- **package-for-appflow.sh**: Creates an AppFlow package with the correct structure
- **prepare-android.sh**: Sets up the Android build configuration

## Usage

1. Clone this repository
2. Copy these files to your main project directory
3. Run the scripts to prepare your builds
